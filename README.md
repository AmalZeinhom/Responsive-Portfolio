# Rayan Portfolio

A responsive portfolio website implemented using HTML5 and CSS3 as part of the GIG Skill Boost Program at Nile University.

## Overview

This project focuses on reviewing and strengthening core front-end development concepts, including:

- Semantic HTML5 structure
- CSS Flexbox and Grid
- Responsive design
- Mobile and tablet layouts
- CSS variables
- Form structure and styling
- Basic accessibility practices
- UI implementation from a provided design
